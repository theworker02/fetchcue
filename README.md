# fetchcue

Fetch numeric cue values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/fetchcue/

## Install / run

```bash
git clone https://github.com/theworker02/fetchcue.git
cd fetchcue
node src/cli.js
node --test
```
